# Монитор барахолок в Telegram

Скрипт следит за чатами-барахолками и ловит объявления про **iPhone Duo** —
и тех, кто хочет купить, и тех, кто продаёт. По каждой находке:

1. присылает уведомление в «Избранное» (текст, автор, ссылка на сообщение);
2. отвечает автору заранее заданным текстом — в личку или прямо в чате.

Обычные iPhone (15 Pro, 13 и т. д.) игнорируются — нужен именно Duo
(`iphone duo`, `айфон дуо`, `айфон-дуо`, `iPhoneDuo`…).

## Установка

Нужен Python 3.10+.

```
pip install -r requirements.txt
copy config.example.yaml config.yaml      (на macOS/Linux: cp)
```

В `config.yaml`:

- `api_id` и `api_hash` — получить на <https://my.telegram.org> → *API development tools*
  (войти по номеру телефона, создать приложение с любым названием);
- `reply.to_buyer` и `reply.to_seller` — ваши тексты ответов.

## Запуск

```
python monitor.py --list-chats   # какие чаты будут отслеживаться ([x])
python monitor.py                # мониторинг
```

При первом запуске скрипт спросит номер телефона и код — код придёт в уже открытый
Telegram на компьютере. Дальше вход сохраняется в файле `monitor.session`
(никому его не передавайте — это доступ к аккаунту).

Чаты выбираются автоматически: все ваши группы, в названии которых есть «барахолка»,
«куплю», «продам» и т. п. Если какой-то чат не подхватился — впишите его в `chats`.
В чатах нужно состоять.

## Пробный режим

По умолчанию `dry_run: true`: скрипт всё находит и уведомляет, но людям **не пишет** —
в уведомлении видно, что он отправил бы. Убедитесь, что находки и тексты верные,
и поставьте `dry_run: false`.

## Защита от блокировки

Telegram ограничивает аккаунты, которые массово пишут незнакомым людям, поэтому:

- одному человеку скрипт пишет один раз за `cooldown_days` (даже если тот разместил
  объявление в десяти чатах);
- не больше `max_per_hour` ответов в час, со случайной паузой перед каждым;
- если Telegram всё же ограничит отправку, автоответы останавливаются,
  а мониторинг и уведомления продолжают работать.

Объявления, где непонятно, покупка это или продажа, приходят только уведомлением.
